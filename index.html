Click inside a paragraph to place the cursor and edit (Enter = done, Esc = cancel). Hover a paragraph: ◀ ▶ change its level · # numbering on/off · ⇡ merge up · ✂ split at the cursor · red / black squares colour the selected text · ✎ edit all (or double-click). Put # at the start of a line in your file for an unnumbered paragraph, * / ** / *** to set its level.

    Recognised main headings: तथ्यगत बेहोरा / तथ्य खण्ड, यस अदालतको ठहर / ठहर खण्ड, तपसिल / तपसिल खण्ड. Typed numbers such as 1.1 or १.१.१ only show the level; this page renumbers everything. Bold, underline, italic, colour and highlight are kept from .docx and .rtf files. Old .doc files are read on a best-effort basis; if the text looks wrong, save as .docx first. Review all output against the original before use.
