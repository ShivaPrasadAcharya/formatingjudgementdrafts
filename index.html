Blue numbers and indents are a preview of the Word auto-numbering levels (1. → 1.1 → 1.1.1 …). The downloaded file contains real automatic numbering.

Recognised main headings: तथ्यगत बेहोरा / तथ्यखण्ड, यस अदालतको ठहर / ठहरखण्ड, तपसिल. Numbers typed in the input are used only as level hints (1. = level 1, 1.1 = level 2, 1.1.1 = level 3 …; the actual values may be any number, e.g. 7.1); the page does the sequential numbering. Unnumbered paragraphs follow the usual numbering style. Use "Use output as input" to feed the numbered output back, fix any level, and press Structure again. Old .doc files are read on a best-effort basis; if the text looks wrong, save as .docx first. Bold, underline and italic are kept from .docx, .rtf and .html files (the input box shows plain text); .doc and .txt files carry no formatting here. Review all output against the original before use.
